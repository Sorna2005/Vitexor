# 🚀 VITEXOR

### AI-Powered Code Review & Analysis Platform

> **Intelligent Code Analysis. Better Code.**

VITEXOR is an AI-powered code review platform that analyzes source code
and provides structured feedback on bugs, security, performance,
maintainability, and possible improvements.

Built with **Python, FastAPI, CodeBERT, FAISS, Gemini, HTML, CSS and JavaScript.**
